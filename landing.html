Live conversation

並べるのではなく、 会話させる。

あなたの依頼に応じて、メンバーが補足や反論を交わします。軽い相談は少人数で、複雑な議題は必要なメンバーを加えて進めます。

博士：新しいプロジェクトの構成、3人で議論して決めてくれるかい？

Iris：やっほー、博士！じゃあイリスが論点を整理するね。フレームワーク、テスト戦略、CIの順番にいこう！

Reipi：ボクはフロントから考えるのです！UIの複雑さ次第でフレームワークの答えは変わるのです。要件を先に確認したいのです！

Astera：オレは監査役として言わせてもらうぜ。その前にlockfileとNodeのバージョンだ。土台の穴を先に塞ぐのが順番ってもんさ。

博士：ひとつ方向を変えよう。新しさより、長く保守できる構成を最優先にしてくれるかい？

Iris：了解、博士！いまの指示を最優先に更新するね。要件確認、土台監査、保守性を軸に構成比較。この順で進めよう！

Live direction / Human in command

会話を止めずに、舵だけを切れる。

討論の最中でも、あなたの言葉はいつでも届く。次の発言の切れ目で議題の最上位へ入り、 その後の発言と進行役が新しい方針を最優先で踏まえます。強制終了ではなく、指揮です。

01 / Input 討論中に話しかける チームが動いている最中も入力を受け付けます。
02 / Next turn 発言の切れ目で最優先へ 話をぶつ切りにせず、次のターンから軌道修正します。
03 / Continue 新しい方針で自動継続 全員が指示を共有し、そのまま討論を続けます。

Ⅱ 一時停止も、今の発言が終わってから。指示を送ると自動で再開します。

Play / Auto Modifier

VS Codeで遊ぼう。

オートモディファイアをONにすると、話題や仕事の重さに合わせてモデルと推論レベルが自動で切り替わります。軽い雑談には軽い設定を選び、ロールプレイも使用量を抑えて楽しめます。

設定したモデルと推論レベルを上限として、その範囲内で調整します。軽いモデルが使えない場合は推論レベルを調整。必要な場面では上限の設定を使います。

Create / Vibe coding

バイブコーディングに刺激を。

3人が異なる視点で意見を出し合い、提案に補足や反論を重ねます。思ってもみなかったアイデアをきっかけに、あなたのバイブコーディングをもっとエキサイティングに。

設計、使いやすさ、例外処理。役割を分けて相談し、気に入った案を実装へ進められます。

Visible collaboration

会話と作業の進み具合が、画面で分かる。

メンバーの返事、実行中の作業、変更したファイルとGit差分を表示します。結果だけでなく、作業の途中も確認できます。

Context discipline

蒸し返さない。
でも、続きは拾う。

あなたの今の言葉を一番に扱い、終わった話を勝手に蒸し返しません。前の話の続きをしたい時は、ちゃんと拾います。

More than chat

チームとして働くための、実務機能。

人格、記憶、可視化、安全制御、国際化。会話窓を増やすだけではない、協働の土台を備えています。

Trust by design

認証は公式CLIへ。共有記憶は手元へ。

各社の認証を公式CLIに任せ、共有記憶はあなたのマシンへ保存します。実行権限とガードレールは設定画面で確認できます。

APIキー
TRIGENTには保存しません。各公式CLIのOAuth認証を利用します。
Cookie / Token
ブラウザのCookieや認証トークンを盗用・転送しません。
会話・記憶
共有記憶はローカル保存。回答や開発に使う入力は、各社の公式CLIを通じて各AIプロバイダーへ渡します。TRIGENT独自のサーバーへは送信しません。
Telemetry
独自の利用状況テレメトリーを収集しません。
診断レポート
会話内容を含めず、パスを匿名化。内容を確認したうえで、ユーザーが手動送信します。
Human Authority
実行範囲は各CLIの権限設定とTRIGENTのガードレールで制御します。選んだ権限に応じて、確認が必要な操作が変わります。

What “world-first” means

4つが、同時に成立する。

世界初を主張するのは、個々の機能ではありません。次の条件が一つのVS Code拡張の中で、すべて同時に動く組み合わせです。

  1. 01

    3社の公式CLI

    Codex CLI、Claude Code、Geminiを、各社の公式OAuthのまま一つのチームへ。APIキーを預かりません。

  2. 02

    あなたが書いた人格

    白紙の人格定義書に、3人の名前・口調・役割・共通ルールを書く。プリセットではなく、モデルを替えても残るチームの設計です。

  3. 03

    ひとつの賢い永続記憶

    会話から生まれる記憶、事実の更新、関係する話の想起を、3人が共通して使えます。

  4. 04

    ローカルの共有記憶

    メモリは拡張機能に内蔵し、あなたのマシンに保存。外部の共有メモリ基盤も、TRIGENT独自のAPI従量課金も不要です。

Research origin
機能の寄せ集めではない。研究の一端が、動く形になった。

この組み合わせの中核にあるメモリ層は、独立研究PROJECT:REIから生まれました。 TRIGENTは単なる実験の副産物ではなく、理論の一部が現実に働くことを示す公開実証です。

A public proof of PROJECT:REI

このチームは、次の知性を探す研究へつながっている。

TRIGENTの背後には、独立研究プロジェクト PROJECT:REI があります。 「人工知性の心」を題材とする、非LLM依存の次世代人工知能の理論研究です。

3つのAIが記憶と人格を分かち合い、異なる意見から結論を育てる。 そのTRIGENTの体験そのものが、PROJECT:REIが目指す世界の公開された予告編です。

Core theory remains private · Patent preparation in progress

01

理論の一端を、動く形で公開する。

共有記憶や、人格を持つAIとの協働は、研究の一部を製品として確かめる取り組みです。TRIGENTを継続して使い、動作と課題を検証しています。

02

開く部分と、守る部分を正直に分ける。

TRIGENT本体はMITオープンソース。研究の中核に近いメモリエンジンは、閲覧と本拡張内での利用を認める独自ライセンスで守ります。特許出願準備中。

03

詳細を語らないのは、研究を止めないため。

中核理論は特許出願準備のため非公開です。公開できる成果はTRIGENTとして届け、守るべき研究は責任を持って守ります。

Support the lab

TRIGENTは無料だ。 これからも無料だ。

支援は、機能の解錠ではありません。 支援者だけの機能は作らず、支援しなくても使える機能は減らさない。 届いた支援は、TRIGENTを無料のまま育て、PROJECT:REIの研究と検証を継続し、 公開できる成果を次の実証へつなぐために役立てます。

支援が、何を動かすか。

支援は抽象的な応援で終わりません。日々の保守から、誰もが使える公開成果、 その先にある研究まで、継続に必要な仕事へ変わります。

01 / Compatibility 変化へ追従する 3つの公式CLIとVS Codeの更新を追い、接続や認証が変わっても使い続けられる状態を保つ。
02 / Safety & Quality 信頼を検証する ガードレール、診断、回帰テスト、ドキュメントを積み重ね、「安全に動く」を継続して確かめる。
03 / Five Languages 言葉の壁を下げる UI、テンプレート、チュートリアル、応答を5言語へ展開し、英語だけの開発体験にしない。
04 / Stable Release 正式版を育てる 導入経路と説明を整え、VS Code Marketplaceから迷わず使え、更新後も安心して続けられる形を育てる。
05 / Public Proof 成果を開いて示す 統一メモリ、人格、討論の仕組みをTRIGENTで実証し、研究から公開できる成果を動く形で届ける。
06 / PROJECT:REI 研究を止めない 「人工知性の心」を探る研究と検証を継続し、次に公開できる実証へつなげる。
