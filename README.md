# TRIGENT-Orchestration

Three AIs. One team. Inside VS Code.

## English

TRIGENT-Orchestration brings the official Codex, Claude Code, and Gemini (Antigravity) CLIs together in one VS Code extension. Give the agents their own personalities and work with them using shared local memory. Use the team for development, discussion, casual chat, and role-play.

The public release is planned as **v1.0.0**. The core research is private while a patent application is being prepared. Source code will be added here when it is ready for publication. This repository currently provides an overview only.

Authentication uses each provider’s official CLI. TRIGENT does not collect API keys or browser cookies. The interface supports English, Japanese, German, Chinese, and Hindi.

## 日本語

TRIGENT-Orchestrationは、Codex・Claude Code・Gemini（Antigravity）の公式CLIを、一つのVS Code拡張へまとめるものです。各エージェントの人格を決め、ローカルの共有記憶を使うチームとして、開発、相談、雑談、ロールプレイを楽しめます。

**v1.0.0で一般公開予定**です。研究の中核理論は、特許出願準備中のため非公開です。ソースコードは公開の準備が整い次第、このリポジトリに掲載します。現在は概要のみを載せています。

認証は各社の公式CLIに任せます。TRIGENTはAPIキーやブラウザのCookieを収集しません。UIは日本語・英語・ドイツ語・中国語・ヒンディー語に対応しています。
